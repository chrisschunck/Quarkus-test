# Objetivo 
Aplicar conhecimento em POO e API REST utilizando o framework Quarkus com RabbitMQ para mensageria 

# Tecnologias 
Java 
Quarkus
Arquitetura Hexagonal e em Camadas
Hibernate
Junit5
Assert
Docker
RabbitMQ
PostgreSql

# Banco de Dados
driver e url do PostgreSql

# Como Rodar
Abrir terminal e rodar cd src do arquivo 
com o docker aberto local rodar:
docker 
docker compose up 
sobe o banco de dados e o rabbitMQ automaticamente
